# 제품 비전

## 한 문장

생산 담당자가 계획과 실제 진행의 차이를 보고, 자재·품질 담당자가 하나의 제조 이력에서 원인과 영향 범위를 추적할 수 있는 센서 제조 MES를 만든다.

## 해결할 문제

생산계획, 자재 입출고, 공정 실적과 품질 판정이 서로 분리되면 다음 질문에 빠르게 답하기 어렵습니다.

- 어떤 작업이 계획보다 지연되고 있는가?
- 이 작업에 실제로 투입된 자재 LOT는 무엇인가?
- 불합격 자재가 어느 생산 LOT와 완제품에 영향을 미쳤는가?
- 누가 어떤 상태를 언제 변경했는가?

이 프로젝트는 그 질문에 일관된 상태 전이와 추적 가능한 데이터로 답합니다.

## 주요 사용자

| 역할 | 핵심 업무 |
|---|---|
| 생산계획 담당자 | 생산계획, 작업지시, 일정과 진척 확인 |
| 현장 작업자 | 자재 투입, 공정 시작·완료, 실적과 이상 등록 |
| 자재 담당자 | 자재 입고·출고·할당, 가용재고와 재공품 확인 |
| 품질 담당자 | 검사 결과, 합격·불합격·보류 판정, 격리와 해제 |
| 시스템 관리자 | 사용자 역할, 기준정보와 감사이력 확인 |

## MVP 수직 흐름

1. 생산계획 담당자가 제품·수량·납기를 기준으로 작업지시를 생성한다.
2. 자재 담당자가 가용한 자재 LOT를 작업지시에 할당한다.
3. 작업자가 공정 순서에 따라 시작·완료 실적과 투입량을 기록한다.
4. 품질 담당자가 필수 검사 결과를 입력하고 상태를 판정한다.
5. 합격한 생산 LOT만 다음 공정 또는 완료 상태로 전이한다.
6. 특정 자재 LOT에서 결함이 발견되면 연결된 생산 LOT와 완제품을 조회해 격리한다.
7. 모든 상태 변경은 행위자·시각·이전 값·새 값과 함께 감사이력에 남는다.

## 핵심 불변조건

- 가용수량보다 많은 자재를 투입할 수 없다.
- 선행 공정이 완료되지 않으면 후속 공정을 완료할 수 없다.
- 필수 검사가 누락되거나 불합격이면 생산 LOT를 완료·출하 승인할 수 없다.
- 확정된 투입·검사 이력은 임의로 덮어쓰지 않고 취소 또는 정정 이벤트로 보정한다.
- 상태를 변경하는 명령은 중복 요청에도 같은 결과를 보장해야 한다.
- 업무상 중요한 상태 전이는 모두 감사 가능해야 한다.

## 성공 기준

- 신규 사용자가 5분 안에 작업지시부터 품질 판정까지 핵심 흐름을 시연할 수 있다.
- 자재 LOT 하나를 기준으로 상·하위 제조 이력을 양방향으로 탐색할 수 있다.
- 동시 요청과 실패 상황에서도 재고와 상태 전이의 정합성이 보존된다.
- 정상 상태뿐 아니라 로딩·빈 상태·오류·권한 없음·충돌 상태가 화면에 명확히 표현된다.
- 주요 도메인 규칙이 단위·통합·E2E 테스트 근거로 남는다.

## 명시적 비범위

- 특정 기업의 실제 공정, 내부 시스템 또는 화면 복제
- 실제 방산 고객·제품·공정조건·검사 기준 사용
- 회계·급여·인사 등 범용 ERP 전체 기능
- PLC 또는 생산설비의 실시간 제어
- 예측 AI를 위한 기능 추가 자체

모든 회사·제품·사용자·LOT·측정값은 시연을 위해 만든 가상 데이터만 사용합니다.
