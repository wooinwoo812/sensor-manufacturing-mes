## 문서를 추가하거나 고칠 때

- 현재 규칙은 해당 기준 문서 한 곳을 고칩니다. 여러 인수인계에 같은 규칙을 복제하지 않습니다.
- 변경 이유·실제로 실행한 검사·실행하지 않은 범위는 인수인계의 해당 날짜·주제에 남깁니다.
- 파일을 추가·이동하면 [문서 목록](../catalog.json)과 [전체 길잡이](../README.md), 해당 링크를 함께 맞춥니다.
- docs:check와 저장소 문서 테스트로 형식·내부 링크·목록 누락을 확인합니다.
- 날짜별 기록을 계속 “최신 추가”로 쌓지 않습니다. 현재 요약과 변경 기록을 나눕니다.
